# Creador de USB de Overty · Mainbit

Herramienta de **Gabriel HernArro** para que cualquier técnico deje una USB lista
para arrancar **Overty Disk** en un clic, con interfaz gráfica y control remoto.

- **Creador de USB** (técnicos): baja el ISO marcado y graba la USB (UEFI/FAT32), verificando el resultado.
- **Panel de control** (solo Gabriel): activa/desactiva la herramienta y cambia el ISO sin recompilar.
- **`control.json`**: interruptor remoto + ISO vigente. Separado del repo del toolkit.

Compilación automática en **Actions** → los `.exe` quedan en **Releases/latest**.

Ver **GUIA-GABRIEL.md** para la puesta en marcha.
